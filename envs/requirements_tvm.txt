# requirements_tvm.txt — ambiente TVM (venv separado do XLA/PyTorch)
#
# IMPORTANTE: o TVM usado no estudo (0.22.dev0, commit 3b60f1c) NÃO é
# instalável via pip — o pacote `apache-tvm` do PyPI parou no 0.14 e não tem
# o módulo `relax` que o backends/tvm_backend.py usa. O TVM precisa ser
# compilado do fonte (com CUDA e LLVM habilitados) e exposto ao venv via
# PYTHONPATH, apontando TVM_HOME para o checkout:
#
#   git clone --recursive https://github.com/apache/tvm && cd tvm
#   git checkout 3b60f1c9b        # commit usado no artigo
#   # build com USE_CUDA=ON e USE_LLVM=ON — ver docs oficiais:
#   # https://tvm.apache.org/docs/install/from_source.html
#
#   make smoke_tvm TVM_HOME=/caminho/para/tvm
#
# Este arquivo instala apenas as dependências de runtime do TVM e do
# benchmark (torch/torchvision para o trace FX do modelo, matplotlib para os
# gráficos do modelo de custo).
#
# O snapshot completo do ambiente original (pip freeze) está preservado em
# env_reports/requirements_tvm_snapshot_original.txt.
#
# Ambiente de referência do artigo: Python 3.11.13, LLVM 20.1.8, CUDA 12.6.
